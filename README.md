# SahyadriSamrakshane
SahyadriSamrakshane 🌿🔥

An Android application built using GenAI + Android Studio to help citizens report environmental issues in the Western Ghats such as forest fires, illegal logging, landslides, and other ecological threats directly to the authorities with accurate GPS coordinates.

📱 Project Overview

The Western Ghats are one of the most sensitive ecological regions in India. Many incidents like:

🌲 Illegal tree cutting
🔥 Forest fires
⛰️ Landslides
🚯 Waste dumping
💧 Water pollution

often go unreported or are reported too late.

SahyadriSamrakshane aims to bridge the communication gap between local communities and forest/environment departments through a simple mobile application.

🚀 Features
📍 Real-time GPS location tracking
📸 Capture and upload incident photos
📝 Report environmental issues instantly
🤖 GenAI-assisted report suggestions
☁️ Firebase database integration
🔔 Emergency alerts and notifications
🗺️ Map-based incident visualization
👥 User-friendly interface
